Programming Academy — Project Presentation

Programming Academy

Web Platform for Self-Learning Programming — Senior Project 2025-2026

Authors: Mohamad Alsaouadi, Ahmad Aghaa, Ahmad Turkmani — Supervisor: Dr. Riad Nyouf

Site Description

This is a lightweight web-based Learning Management System for Arabic-speaking learners. It provides structured programming courses, lesson videos, interactive challenges, assignment submissions, and progress tracking. The platform is built for local deployment (XAMPP) and emphasizes privacy, simplicity, and low operational cost.

Problem Statement

  • Absence of a unified, simple platform with structured programming courses.
  • No reliable progress tracking for self-learners.
  • Existing solutions are complex or lack localized Arabic support.

Objectives & Scope

  • Design and implement a modular LMS for programming.
  • Provide authentication, course management, challenges, and progress tracking.
  • Integrate a local AI helper (LLM) for contextual guidance.

Architecture & Tech Stack

  • Client-Server model — Fetch API for async communication.
  • Frontend: HTML5, CSS3, Vanilla JavaScript (no frameworks).
  • Backend: PHP with PDO; Database: MySQL/MariaDB.
  • Local LLM via Ollama running Qwen-Coder for AI assistance.

Database Design (Core)

  • Core tables: users, courses, lessons, assignments, challenges.
  • Tracking: user_lesson_progress, user_course_progress, challenge_attempts.
  • RBAC: roles and user_roles for admin protection.
  • Optimized for relational integrity and scalability.

Backend Techniques & APIs

  • API Pattern: REST-style PHP endpoints returning JSON with `success` and `message` fields; CORS headers and session checks on protected routes.
  • Authentication: `login_api.php` uses PDO prepared statements, `password_verify()` for bcrypt passwords, and server-side `$_SESSION` for state.
  • Content APIs: `fetch_courses.php` / `fetch_lessons.php` return compact JSON (pagination-ready); backend performs input validation and error codes.
  • Progress APIs: `update_progress.php` and `fetch_user_progress.php` use upsert patterns (INSERT ... ON DUPLICATE KEY UPDATE) to track lesson completion and resume position efficiently.
  • Admin Endpoints: Protected by RBAC checks; file uploads handled via `upload_handler.php` with server-side validation and path sanitization.
  • Infrastructure: Centralized DB connection (`db_connect.php`), `includes/ApiResponse.php` for consistent responses, and `includes/ErrorLogger.php` for server-side logging and diagnostics.
  • Performance: Database views and strategic indexes improve JOIN performance; backup scripts provide automated database dumps and retention.

AI Helper — Overview

  • Local LLM approach using Qwen-Coder via Ollama (low latency, privacy).
  • Two modules: `ai_helper_challenges.php` (hints & verification) and `ai_helper_projects.php` (project guidance).
  • Verdict system: strict Yes/No evaluation with concise Arabic hints.

AI Helper — Implementation Details

  • Verification Mode: analyzes submitted code and returns verdict + hint.
  • Hint Mode: single-line Arabic hints to avoid giving full solutions.
  • Chat Mode: follow-up Q&A within challenge context.
  • Anti-cheating: prompt engineering enforces tutor behavior; size guard (8KB) for inputs.

Frontend Techniques & Implementation

  • Dynamic Rendering: `fetch()` requests to backend return JSON; JavaScript templates generate course cards and lesson lists for fast UI updates.
  • State Management: `sessionStorage` stores transient session data (current video index/position); persistent progress saved via API calls to backend.
  • Video Player: HTML5 `
  • Network Resilience: Fetch error handling, retries for transient failures, and graceful UI fallbacks when APIs are unavailable.
  • Performance Optimizations: Lazy-loading course thumbnails, minimizing DOM updates via document fragments, and simple client-side caching for repeated queries.
  • Accessibility & RTL: Semantic HTML, ARIA attributes where needed, and full RTL layout support for Arabic users with proper text direction handling.
  • CSS Techniques: CSS variables for theming, responsive breakpoints, and Grid/Flexbox for layout; minimal dependencies to keep frontend lightweight.

Authentication & Security

  • Passwords hashed with bcrypt via PHP `password_hash()`.
  • PDO prepared statements to prevent SQL injection.
  • Server-side sessions (`$_SESSION['user_id']`) and RBAC enforcement.
  • Input validation and XSS mitigation on rendering.

Progress Tracking Flow

  • markComplete() triggers JS -> POST to `update_progress.php`.
  • Backend inserts/updates `user_lesson_progress` and prevents duplicates.
  • `fetch_user_progress.php` computes completion percentage for UI.
  • Video position saved to allow resume behavior.

Admin Panel Features

  • RBAC-protected admin interface — manage courses, lessons, assignments.
  • Upload handling: `upload_handler.php` stores files and metadata.
  • Platform analytics and content moderation tools.

Testing & Results

  • Authentication tests: pass for valid/invalid/empty cases.
  • Core functionality: video playback, progress saving, admin access — all pass.
  • Compatibility: Desktop, laptop, mobile — responsive UI verified.
  • Database operations and API responses validated in test cases.

Non-Functional Requirements

  • Performance: pages aim to load within 2 seconds under normal conditions.
  • Security: bcrypt, prepared statements, XSS protection.
  • Scalability: normalized schema supports adding courses without structural change.
  • Compatibility: responsive across devices and RTL-ready.

Limitations & Future Work

  • Current: local video hosting; offline mode not available.
  • Future: payment gateway (Stripe/PayPal), live code sandbox (Piston), cloud deployment (AWS/Azure), social features.

Key Achievements

  • Complete LMS built with PHP/MySQL and Vanilla JS frontend.
  • Integrated local LLM (Qwen-Coder) for intelligent assistance.
  • Secure authentication, RBAC, progress tracking, and admin tools implemented.
  • Comprehensive testing with successful results.

Conclusion

The Programming Academy platform meets its objectives: usability, security, scalability, and provides a foundation for further enhancements.
